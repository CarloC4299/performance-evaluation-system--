# 📊 绩效评价系统 | Performance Evaluation System

营销中心季度绩效评价系统，支持多人协作打分、多月份汇总、自动计算。

## 功能特点

- **多人协作打分**：支持多评委同时在线评分，数据实时汇总
- **多月份汇总**：可跨季度汇总绩效数据，生成趋势分析
- **自动计算**：加权得分自动计算，减少人工操作误差
- **可视化展示**：绩效结果以图表形式直观呈现

## 文件说明

| 文件 | 说明 |
|------|------|
| `index.html` | 绩效评价系统主页面（多人协作打分+汇总） |
| `营销中心季度绩效评价表.html` | 季度绩效评价表（单次评价使用） |
| `icons/` | PWA图标资源 |
| `manifest.json` | PWA配置文件 |
| `service-worker.js` | 离线缓存服务 |

## 使用方式

直接用浏览器打开 `index.html` 即可使用，无需安装任何依赖。

## 技术栈

- 纯前端实现（HTML + CSS + JavaScript）
- 支持PWA离线使用
- 数据存储在浏览器本地
